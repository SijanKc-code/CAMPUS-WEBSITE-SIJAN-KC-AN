            About CampusFlow

            Smart Student Productivity Hub

            Developer: Sijan KC   Section: AN

            Course: BTech Computer Science and Engineering, GLA University, Mathura

            Stack: HTML5, CSS3, Vanilla JavaScript, browser localStorage

            Objectives

            Help students organise assignments, plan study time, focus with a Pomodoro timer and see their progress.

            Target users

            College students, especially first-year engineering and CS students.

            Key features

            Assignment manager, study planner, focus timer, analytics, light/dark theme, responsive layout.

            Learning outcomes

            DOM manipulation, events, forms and validation, localStorage, responsive CSS and accessibility.

            The app runs locally in the browser and can be hosted as a static website. Data is stored in the current browser and is not synchronised across devices.
